# WhyPanel

Explication d'une recommandation : décomposition du score, données utilisées, limites et alternatives. Ouvert par « Pourquoi ? » sur une carte, un nœud ou une ligne.

**Le consommateur fournit** le score et ses quatre composantes, la liste des champs lus (fichier et champ), les limites connues, les alternatives proches.

- S'ouvre sous la rangée de cartes (dans le widget) ou en tiroir latéral en plein écran ; Échap ferme.
- Barres de composantes en `gold` sur `surface-sunken`, valeur sur 25 à droite.
- Une estimation utilisée dans le calcul apparaît dans les données avec son badge.
- La méthode complète est décrite dans la section Méthodes de calcul du design system.
