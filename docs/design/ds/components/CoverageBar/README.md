# CoverageBar

Barre segmentée fine (8 px) : part documentée, estimée et absente d'un champ. Utilisée par le widget Couverture des données.

- Segments `p-doc` (`ink-2`), `p-est` (`estimate`), `p-null` (hachures) séparés par 2 px ; extrémités arrondies.
- Le chiffre clé est écrit en clair à droite (« 150 sur 335 documentés ») ; la barre a un `aria-label` complet.
- Légende commune sous la liste.
