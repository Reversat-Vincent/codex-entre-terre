# CommandPalette

Recherche globale sur les 18 fichiers, ouverte par Ctrl/⌘ + K ou le champ de la barre supérieure.

- Résultats groupés par type (Armes, Armures, Sorts, Boss, Lieux, PNJ, Objets, Compétences, Mécaniques), cinq par groupe puis « Voir les N ».
- Chaque résultat : icône du type, nom avec la partie trouvée en `mark` (`gold-text`), badge de source, une ligne de contexte (classe, lieu, champ où le terme a été trouvé).
- Recherche insensible aux accents et à la casse, tolérante aux fautes légères ; correspondance aussi dans les compétences et les lieux d'obtention.
- Clavier : ↑ ↓, Entrée ouvre la fiche, Tab parcourt les filtres de type, Échap ferme. Sans saisie : recherches récentes et éléments de Ma liste.
