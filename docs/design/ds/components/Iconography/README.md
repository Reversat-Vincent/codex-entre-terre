# Iconography

Jeu d'icônes original au trait : grille 24 × 24, trait 1,6, extrémités et angles arrondis. Les symboles `i-*` de cet aperçu forment le sprite à reprendre tel quel.

- Usage : `<svg class="cx-i"><use href="#i-search"/></svg>`. L'icône hérite de `currentColor` ; `.sm` 14 px, `.xs` 12 px, `.lg` 20 px, `.xl` 24 px.
- Types de dégâts (`i-d-*`) et statuts (`i-st-*`) se teintent avec `dmg-*` et `st-*` via les classes `.dt-*` et `.st-*`.
- Sources : carré (Base), demi-cercle plein (SotE), losange (TP) : la forme distingue la source sans la couleur.
- Classes d'armes : silhouettes simples en diagonale ; une classe sans icône dédiée prend l'icône de sa famille la plus proche.
- Aucune icône, logo, illustration ni police du jeu. Pas d'emoji.
