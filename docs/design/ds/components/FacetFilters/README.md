# FacetFilters

Filtres propres à chaque catalogue, dans une colonne de 240–280 px à gauche des résultats.

**Le consommateur fournit** les facettes du type d'entrée et leurs compteurs, recalculés à chaque changement.

- Armes : classe, contenu, scaling dominant, prérequis atteints, type d'amélioration, effet passif, région.
- Armures : emplacement, poids, équilibre, absorption. Sorts : type, école, prérequis, coût en FP. Boss : rang, région, obligatoire, Remembrance. Lieux : type, région.
- Chaque option affiche son compteur ; une option à 0 reste visible et désactivée.
- Les filtres actifs sont rappelés en puces au-dessus des résultats, avec « Effacer ».
- Les estimations ont leur propre case, cochée par défaut, avec le badge Estimation et leur nombre.
- Plus de cinq options : les cinq plus fréquentes, puis « Voir les N autres ».
