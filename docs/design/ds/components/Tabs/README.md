# Tabs

Onglets d'une fiche : rencontres d'un boss, affinités d'une arme, sections longues.

- `role="tablist"`, `role="tab"` avec `aria-selected`, `role="tabpanel"` ; flèches ← → pour passer d'un onglet à l'autre.
- Onglet actif : texte `ink` et soulignement `gold` de 2 px.
- Un onglet de rencontre porte le lieu puis la région (`.cx-tab-n`), et son propre badge de source dans le panneau.
- Un boss à une seule rencontre n'a pas d'onglets.
