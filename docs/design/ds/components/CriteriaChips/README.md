# CriteriaChips

Résumé des critères actifs en haut du tableau de bord. Lecture en un coup d'œil, retrait en un clic.

- `.cx-chip` avec un libellé `.k` (« Origine ») et la valeur. Le build cible, s'il existe, est `.is-on`.
- `.cx-chip-x` retire un critère facultatif ; les critères obligatoires (contenu, niveau) n'ont pas de croix.
- Cliquer une puce ouvre la section correspondante du panneau de critères.
- Sur mobile, la rangée défile horizontalement.
